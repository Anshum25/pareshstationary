# Paresh Stationery Mart website

Build a polished, responsive, single-page local shop website at `/`, using the supplied business brief and existing TanStack/Tailwind project.

## Experience
- Establish a distinctive paper-and-ink visual system with the requested navy, red-orange, warm paper, and yellow palette; responsive layout; dark mode control; reduced-motion support; and a short, optional intro.
- Add sticky anchor navigation, an animated stationery-led opening, category grid, cartridge-refilling process, benefits, bulk enquiry, about, gallery/lightbox, clearly identified sample testimonials, FAQ, contact details/forms, and footer.
- Make phone, email, and WhatsApp actions work, use an embedded map, and keep the optional language toggle out of scope unless time permits.
- Use a central shop-content file; use original generated imagery rather than external image hotlinks.

## Technical notes
- Keep the requested long-scroll experience on `/` and implement with the existing TanStack Start and Tailwind v4 stack; do not replace the framework.
- Implement interactions accessibly with lightweight CSS/React behavior and existing icon tooling where available; do not add heavy motion libraries unless already installed.
- Add unique page metadata and LocalBusiness JSON-LD; do not invent hours, business history, customer counts, or real reviews.
- Validate the preview, responsive layout, accessible interactions, and current build log after implementation.
